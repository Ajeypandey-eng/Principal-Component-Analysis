# Principal-Component-Analysis
This repository contains two hands‑on Colab notebooks demonstrating Principal Component Analysis (PCA) through both a manual step‑by‑step approach and the scikit‑learn module.

🔹 Manual PCA:

Calculates covariance matrices, eigenvalues, and eigenvectors directly

Iteratively drops columns to extract principal components

Builds intuition about how PCA works under the hood

🔹 Module‑based PCA (scikit‑learn):

Fast and efficient dimensionality reduction using sklearn.decomposition.PCA

Scales easily to large datasets

Industry‑standard implementation for real projects
